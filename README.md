# Mini Katalog Flutter

## Proje Açıklaması
Bu proje Flutter kullanılarak geliştirilmiş basit bir Mini Katalog uygulamasıdır.

## Özellikler
- Ürün listesi görüntüleme
- Ürün detay sayfası
- Sepete ürün ekleme
- Sayfa geçişleri (Navigator)
- Görsel kullanımı

## Kullanılan Flutter Sürümü
Flutter SDK

## Çalıştırma Adımları
bash
flutter pub get
flutter run
