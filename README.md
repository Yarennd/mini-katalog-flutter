# Mini Katalog Flutter

## Proje Açıklaması

Bu proje Flutter kullanılarak geliştirilmiş basit bir mini katalog uygulamasıdır. Kullanıcılar ürünleri listeleyebilir, ürün detaylarını görüntüleyebilir ve sepete ekleme işlemini simüle edebilir.

## Özellikler

- Ürün listesi görüntüleme
- Ürün detay sayfası
- Sepete ürün ekleme
- Sayfalar arası geçiş (Navigator)
- Görsel kullanımı

## Kullanılan Teknolojiler

- Flutter
- Dart
- Material Design

## Kullanılmış Flutter Sürümü

- Flutter SDK
- Dart SDK

## Proje Yapısı

text
lib/
├── Pages

├── Components
└── main.dart


## Projeyi Çalıştırma Adımları

1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. Terminali proje klasöründe açın.
3. Aşağıdaki komutu çalıştırın:

bash
flutter pub get


4. Ardından uygulamayı başlatın:

bash
flutter run
